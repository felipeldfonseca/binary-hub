# Arquivo

Documentos de antes da reconstrução (out/2026), guardados só para consulta: PRD, plano de negócio, marketing, especificações da plataforma social e do backend Firebase, relatórios de sprint e a especificação da API antiga.

Eles descrevem um produto e uma arquitetura que não existem mais: o backend Firebase foi removido e o app roda em Next.js, Supabase e Vercel. Para o estado atual, veja o `README.md` e o `CLAUDE.md` na raiz.

`raiz/` reúne os relatórios que ficavam na raiz do repositório e o antigo guia de testes do app. `api/` tem a especificação OpenAPI do backend antigo.
